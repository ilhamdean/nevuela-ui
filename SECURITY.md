# Security Policy

## Supported Versions

Only the latest published version on npm receives security fixes.

## Reporting a Vulnerability

Please do not open a public GitHub issue for security vulnerabilities.

Instead, report privately via [GitHub Security Advisories](https://github.com/ilhamdean/nevuela-ui/security/advisories/new)
for this repository.

Include:

- A description of the vulnerability and its impact
- Steps to reproduce, or a minimal repro
- Affected version(s)

We'll acknowledge your report and aim to release a fix as soon as possible. Once resolved, we'll
credit you in the release notes unless you prefer to stay anonymous.
