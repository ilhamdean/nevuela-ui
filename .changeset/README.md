# Changesets

This directory holds pending changesets — one Markdown file per unreleased change, generated by
`pnpm changeset`. Each file records which packages changed, the semver bump (patch/minor/major),
and a summary; it becomes a `CHANGELOG.md` entry and drives the version bump on release.

Read more: https://github.com/changesets/changesets/blob/main/docs/intro-to-using-changesets.md
